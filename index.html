So funktioniert die App

Tippe einmal auf «Neues Set generieren» — die App stellt sofort ein abwechslungsreiches Einsing-Programm für deine Probe zusammen.

Aufbau jedes Sets

Jedes Set folgt dem didaktischen Aufbau:

Körper Atem Stimme ×3 Kanon

Die App wählt bei jedem Tippen andere Übungen aus — so bleibt das Einsingen abwechslungsreich.

App zum Home-Bildschirm hinzufügen

  • Safari öffnen und diese Seite aufrufen.
  • Unten auf Teilen tippen (Quadrat mit Pfeil nach oben).
  • «Zum Home-Bildschirm» wählen → Hinzufügen.
  • Die App erscheint danach als Icon auf deinem iPhone.

Hinweis

Die App läuft im Browser — eine Internetverbindung ist beim ersten Laden nötig. Eigene Übungen können später hinzugefügt werden.
